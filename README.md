# 🌱 Task Garden

Task Garden is a responsive task management dashboard that helps users organize daily tasks, track productivity, record moods, and stay focused.

## ✨ Features

* ➕ Add, edit, and delete tasks
* ✅ Mark tasks as completed or pending
* 🎯 Set task priorities, categories, and due dates
* 🔍 Search, filter, and sort tasks
* 📊 Track daily progress and goals
* 🌸 Record moods and view mood history
* 📈 View productivity and mood charts
* ⏱️ 25-minute Focus Mode timer
* 🔔 Browser notifications and reminders
* 🌙 Light and Dark themes
* 📱 Responsive, mobile-friendly design
* 💾 Save tasks and settings using Local Storage

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

# 🌷 Task Garden — To-Do List & Mood Tracker

A simple and responsive productivity dashboard built with HTML, CSS, and JavaScript. Task Garden helps users organize daily tasks, track productivity, record moods, and stay focused.

## 🚀 Live Demo

[**Open Task Garden 🌸**](https://duaa-ctrl.github.io/To-do-list-and-mood-tracker/)

## ✨ Features

* ✅ Add, edit, and delete tasks
* 📌 Mark tasks as completed or pending
* 🎯 Set task priorities and categories
* 📅 Add due dates and reminders
* 🔍 Search, filter, and sort tasks
* 📊 Track daily progress and productivity
* 🌱 Set daily goals
* 💗 Record daily moods and notes
* 📈 View productivity and mood charts
* ⏳ 25-minute focus timer
* 🔔 Browser notifications and reminders
* 🌙 Light and Dark themes
* 💾 Save tasks and settings using Local Storage
* 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Browser Local Storage
* Browser Notifications API

## 💻 How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start organizing your tasks and tracking your mood!

# 🌷 Task Garden — To-Do List & Mood Tracker

A simple, interactive, and responsive productivity dashboard designed to help you organize daily tasks, track your mood, build productive habits, and stay focused. 💗

## 🌐 Live Demo

✨ **[Open Task Garden — Live Website](https://duaa-ctrl.github.io/To-do-list-and-mood-tracker/)**

## 📸 About the Project

Task Garden is a personal productivity web application that combines task management, mood tracking, daily goals, and focus sessions in one place. Its simple interface helps users manage everyday activities while keeping track of their emotional well-being.

## ✨ Features

* ✅ Add, edit, and delete tasks
* 📌 Mark tasks as completed or pending
* 🎯 Organize tasks by priority and category
* 📅 Set due dates and reminders
* 🔍 Search, filter, and sort tasks
* 📊 Track daily progress and productivity
* 🌱 Set daily goals
* 💗 Record daily moods and personal notes
* 📈 View productivity and mood charts
* ⏳ Built-in 25-minute focus timer
* 🔔 Browser notifications and reminders
* 🌙 Switch between light and dark themes
* 💾 Save tasks and settings using Local Storage
* 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

* **HTML5** — Page structure
* **CSS3** — Styling and responsive layouts
* **JavaScript** — Interactive features and application logic
* **Browser Local Storage** — Saving tasks and settings
* **Browser Notifications API** — Reminders and notifications

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/DUAA-CTRL/To-do-list-and-mood-tracker.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Start organizing your tasks and tracking your mood! 🌸
